I did this project during my time at S1 Industries. What started as a small introduction into Augmented Reality Apple Vision Pro app development quickly turned into a longer-term project. During this project I learned how to code in Swift and how to further develop my documentation skills. I also had the opportunity to lead the development of an app through the entire development cycle.

During my time at S1 Industries, there was an emphasis on documenting code. While I was already documenting all my functions, they had an emphasis on extra documentation for lines of code that were confusing to implement and for complicated code. The main reason was so that if I was to ever return to old code, I could instantly tell what the code was doing. This meant that not only did I have documentation for each function on what it did, but also many lines of code had additional documentation on what exactly was happening. While this took longer initially to write code, I found it was much easier to return to old code. I now use this methodology for my code and will definitely continue to do this into all my future projects.

By the end of the development of the app, I had created an extensive testing procedure to ensure the app was functioning properly and met the specifications we had set. I also devised a system for taking in feedback and bug reports with a timeline for integrating updates. Lastly we performed our testing internally with a small community of users through TestFlight. By the end of development, we had an app store ready app, meaning that if we wanted to at any moment we could publish it to the app store.

The app itself was written in Swift and had a vertically floating Tic-Tac-Toe board in the immersive environment. The app also supported remote play with up to 4 people using SharePlay, with and without Apple Personas.

This was my first time leading and seeing the development of an app throughout the entire development cycle and was an invaluable experience which I now apply to all my future projects.
